Nhận: .docx, .pdf (file lớn tự động tách nhỏ), ảnh chụp văn bản (jpg/png), .xlsx, .csv, .txt. PDF/ảnh scan vẫn đọc được nhưng độ chính xác thấp hơn — rà kỹ hơn.

Cách khác: dùng khung chat Gemini miễn phí — không cần API key

Dùng chính tài khoản Gemini bạn đang có, không tốn key, không giới hạn như API miễn phí. Ba bước:

  1. Bấm Copy câu lệnh bên dưới (đã kèm sẵn danh sách trường của mẫu đang chọn).
  2. Mở gemini.google.com → dán câu lệnh → đính kèm các tài liệu nguồn (PDF, Word, ảnh) → gửi.
  3. Copy khối JSON Gemini trả về → quay lại đây, bấm Dán kết quả JSON → dán vào ô → Áp dụng.

Hướng dẫn sử dụng

Quy trình chuẩn

1. Vào Thư viện mẫu → thêm file mẫu Word (một lần duy nhất). Chỗ dữ liệu thay đổi theo dự án được đánh dấu {{ten_truong}} màu đỏ; khung pháp lý chữ đen giữ nguyên.

2. Vào Soạn văn bản → chọn mẫu → upload các tài liệu căn cứ → bấm AI rút trích.

3. Rà soát phiếu dữ liệu: đối chiếu từng giá trị với trích đoạn nguồn. Sửa trực tiếp nếu sai. Đặc biệt: giá gói thầu, giá trúng, số/ngày quyết định, % chênh lệch.

4. Bấm Ghép: chọn Bản rà soát (giá trị điền màu đỏ, dễ soi) hoặc Bản trình ký (toàn bộ chữ đen). Bước ghép chạy bằng script, không qua AI — chính xác tuyệt đối về chính tả và giữ nguyên định dạng mẫu.

Triết lý an toàn

Máy soạn nhanh 95%, người kiểm 5% còn lại — không tin tuyệt đối vào bước AI rút trích. Trường nào AI không tìm thấy sẽ để trống và giữ nguyên tag đỏ trong file để bạn không bỏ sót.

Dùng trên nhiều tài khoản Claude

Thư viện mẫu lưu riêng theo từng tài khoản. Để đồng bộ: tài khoản A bấm Xuất thư viện → lưu file .json → mở app bằng tài khoản B → Nhập thư viện. Phiếu data.json của từng văn bản cũng tải/nhập được tương tự — tiện lưu hồ sơ hoặc soạn tiếp trên máy khác.

Lưu ý khác

· Tài liệu nguồn nhận nhiều định dạng: Word (.docx), PDF, ảnh chụp văn bản (jpg/png — chụp bằng điện thoại cũng được), Excel (.xlsx), .csv, .txt. PDF lớn được tự động tách nhỏ thành từng phần để AI đọc ổn định.

· PDF/ảnh dạng scan vẫn đọc được nhờ AI nhìn ảnh, nhưng cần rà kỹ hơn bản chữ.

· Phiếu dữ liệu tự lưu trong lúc soạn — lỡ đóng trang mở lại vẫn còn. Bấm "Xóa phiếu" khi bắt đầu văn bản mới.

· Bản trình ký chuyển mọi chữ đỏ thành đen (trừ tag chưa điền — giữ đỏ để cảnh báo). Nếu mẫu có chữ đỏ "thật" cần giữ, dùng Bản rà soát rồi chỉnh trong Word.

· Mẫu có quốc huy, khung, bảng biểu: giữ nguyên — script chỉ đụng vào chữ placeholder.

Chọn AI (bắt buộc khi chạy ngoài claude.ai)

App này chạy được ở 3 nơi, mỗi nơi cần chọn chế độ AI khác nhau trong mục Cài đặt AI đầu trang:

· Mở trên web (Vercel, GitHub Pages) hoặc mở file từ máy → chọn Gemini (key miễn phí, mỗi người tự lấy tại aistudio.google.com/apikey), hoặc Claude API key (trả phí), hoặc Máy chủ trung gian.

· Bên trong claude.ai (dạng artifact) → chọn Claude tích hợp sẵn, không cần key.

· Chia sẻ cả cơ quan mà không ai phải nhập key → quản trị thêm file api/ai.js vào kho, đặt key trong Environment Variables của Vercel, mọi người chọn chế độ Máy chủ trung gian. Xem file HUONG_DAN_VERCEL.

Kéo thả file

Mọi khung có viền đứt đều nhận kéo thả: thả 1 file .docx vào khung "Chọn file mẫu", thả nhiều file cùng lúc vào khung "Tài liệu nguồn". Thả vào bất kỳ đâu trên trang cũng được — app tự đưa vào đúng ô đang mở.

Dữ liệu và sao lưu

· Sao lưu toàn bộ ra máy (tab Thư viện) là bản gốc bền nhất — cất file vào Drive/USB, khôi phục được ở bất kỳ máy nào.

Dùng chung cả cơ quan qua GitHub

Người quản trị làm 1 lần (chi tiết trong file HUONG_DAN_GITHUB): tạo kho công khai → tải file app này lên, đổi tên thành index.html → bật GitHub Pages (hoặc deploy Vercel) → gửi link cho mọi người. Tạo token (Settings → Developer settings → Fine-grained tokens, chỉ cấp quyền Contents Read&Write cho đúng kho) → dán vào mục "Đồng bộ GitHub" → bấm Đẩy thư viện lên GitHub.

Đồng nghiệp: mở link app → chọn chế độ AI theo hướng dẫn quản trị → mục Đồng bộ GitHub chỉ cần nhập tên kho (không cần token) → app tự tải thư viện mẫu chung mỗi lần mở.
